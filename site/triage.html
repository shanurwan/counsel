Counsel

A triage note for every new issue. Never on the issue.

Counsel Triage is a free GitHub App. When someone opens an issue on your public repository, it writes a short note for you: what is being reported, which area it touches, what information is missing, and a possible duplicate it has checked exists. The note goes to one issue in your repository, Counsel triage notes. The reporter never sees a bot reply.

Install on a repository

Free. One public repository is enough. Uninstall any time and it stops on the next run.

What it does, and what it never does

Does

  • Reads new issues on repositories you installed it on
  • Writes one note per new issue on the notes issue
  • Names a duplicate only if that issue exists; code checks the number

Never

  • Replies on the reporter's issue
  • Labels, assigns, closes or edits anything
  • Triages issues opened before you installed it

GitHub's Issues: write permission, which it needs to post a note, would also allow labelling or closing. Counsel's code never does either; it is open source, and the part that talks to your repository is one file.

What happens to your issues' text

  • Public repositories only. If you install it on a private one, that repository is skipped.
  • The issue's title and body are stored in Counsel's database (Supabase, EU) and sent to a hosted model (NVIDIA's API, Nemotron) to write the note.
  • Ask, and everything stored from your repository is deleted: open an issue on shanurwan/counsel.

Who runs it

One developer, Wan Nur Shafiqah, as part of Counsel, an agent platform where agents can draft but never decide. It runs on free tiers, so it may lag behind a busy repository. Your 👍 and 👎 on the notes are how it gets judged: the results, misses included, are published in the field report.

Stop it

Your repository's Settings → GitHub Apps → Counsel Triage → Uninstall, or your account's Settings → Applications. Counsel stops reading and posting on the next run, within 30 minutes.
